digital-agency-design-system の使い方

Web 画面や HTML の文書を、誰が作っても品質の下限を割らないようにするための Claude のプラグインです。デジタル庁デザインシステム（DADS）を土台に、作る・審査する・直すの3つを手伝います。

何ができるか

役 すること 使える場所
作る DADS の部品で Web 画面・フォーム・マニュアルなどを作る。作り終えたら自動で軽く点検する チャット・Cowork・Claude Code
審査 ページを実際に表示して、アクセシビリティ（JIS X 8341-3・WCAG 2.2 AA）、DADS への準拠、表示、文言を点検する。自分では直さない Cowork・Claude Code
直す 審査の指摘を直し、最後にもう一度審査する Cowork・Claude Code

チャットではページを実際に表示できないため、審査と直しは Cowork か Claude Code で頼んでください。PowerPoint の資料は slide-techvan の担当です。

入れ方

Claude デスクトップアプリ（チャット・Cowork）

  1. 1. 左下の自分の名前 →「設定」→ 設定の左のメニューの「プラグイン」を開く
  2. 2. 右上の「＋ 追加」→「マーケットプレイスを追加」→「リポジトリから追加」
  3. 3. URL に kishi-satoshi/digital-agency-design-system-dist を入れて「同期」
  4. 4. 表示された digital-agency-design-system を「インストール」

Claude Code

/plugin marketplace add Kishi-Satoshi/digital-agency-design-system-dist
/plugin install digital-agency-design-system@digital-agency-design-system-dist

以前にこのスキルを zip でアップロードした人や、~/.claude/skills/digital-agency-design-system に入れていた人は、先にそちらを外してください。同じ名前のスキルが2つあると、どちらが使われたか分からなくなります。

使い方

コマンドは要りません。普通に頼むだけで使われます。DADS やデジタル庁の名前を出す必要もありません。

作る

社内向けの備品申請フォームを、1 ファイルの HTML で作って。

作り終えると自動で軽く点検し、大事な問題が残っていれば上位3件だけ一言添えます。

審査する

このページを審査して。https://www.example.co.jp/

指摘は番号付きで返り、記録は作業フォルダの .dads-review/日時-対象名/ に残ります（指摘一覧 findings.md、スクショ、道具の記録）。翌日以降も番号で直しを頼めます。

直す

さっきの審査の指摘 1 と 3 を直して。

Git で管理しているフォルダでは別ブランチで直し、push や PR の作成の前に確認します。Git で管理していないファイルは、元のファイルを残して 名前.dads-fixed.html に保存します。

報告書にする

この審査結果を報告書にして。

提出用の報告書を DADS のデザインの HTML で作ります。報告書は事前点検であり、JIS X 8341-3 への適合を表明するものではありません。

指摘の重大度

重大度 決め方 直す役の動き
致命的WCAG のレベル A の違反（使えない人が出る）確認せずに直す
重要WCAG のレベル AA の違反確認せずに直す
軽微それ以外（見た目の細部、文言の平易さなど）確認してから直す
DADS の印重大度とは別に、DADS から外れているもの（トークン外の色、独自の部品など）確認してから直す（作ったばかりのページは確認しない）

守るものを伝える（DADS-PROTECT.md）

顧客のロゴやブランド色、テンプレートなど、DADS より優先して守るものがあるプロジェクトでは、プロジェクトの直下に DADS-PROTECT.md を置いてください。書かれたものは、変える前に必ず確認されます。

# 守るもの

## 守るファイル・フォルダ
- templates/master.pptx
- src/components/customer/**

## ブランド色
- #0F2350（顧客のコーポレートカラー）

## 顧客の基準
- docs/customer-guideline.pdf

## メモ
- ロゴの余白は変えない

ファイルが無くても、ロゴやブランド色らしきものを見つけたときは、直す前に確認されます。

審査に使うブラウザ

審査ではページを実際に表示するため、Playwright と Chromium（合わせて約 200MB）を使います。Cowork や Claude Code のクラウドでは自動で入ります。自分の PC で初めて審査するときは、入れてよいかを聞かれます。断ると、その審査は「未点検」になります。

更新を受け取る

プラグインの画面（左下の名前 →「設定」→「プラグイン」）の「＋ 追加」→「マーケットプレイスを管理」で digital-agency-design-system-dist を同期し、「自分のもの」の digital-agency-design-system を更新します。新しく始めた会話から反映されます。

このプラグインについて

  • テクバン社内での利用を目的としたものです。
  • デジタル庁デザインシステムを個人がプラグインにしたもので、デジタル庁の公式配布物ではありません。上流はいずれも MIT ライセンス（著作権者：デジタル庁）です。
  • 審査は事前点検であり、JIS X 8341-3 への適合を表明するものではありません。
