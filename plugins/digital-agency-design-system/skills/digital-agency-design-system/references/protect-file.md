# 守るものの宣言ファイル（DADS-PROTECT.md）

プロジェクトの中に、DADS より優先して守るもの（ロゴ、ブランド色、スライドマスタ、顧客の部品、顧客の基準）があるときに、プロジェクトの直下に置く Markdown のファイル。作る・審査・直すのどの役も、作業の前に探して読む。

## 書式

見出しは次の4つに決めてある（無い見出しは省いてよい）。中身は箇条書き。

```markdown
# 守るもの

## 守るファイル・フォルダ
- templates/master.pptx
- src/components/customer/**

## ブランド色
- #0F2350（顧客のコーポレートカラー）

## 顧客の基準
- docs/customer-guideline.pdf

## メモ
- ロゴの余白は変えない
```

- **守るファイル・フォルダ**：変えてはいけないファイル。`**` で配下のすべてを表す。
- **ブランド色**：DADS のトークンになくても使ってよい色。審査では「トークン外の色」として指摘しない。
- **顧客の基準**：顧客のスタイルガイドなど。DADS より優先する。読める形式なら読んで従う。
- **メモ**：上に当てはまらない約束ごと。

## 読み方

1. 作業を始める前に、プロジェクトの直下（無ければ Git のリポジトリの直下）に `DADS-PROTECT.md` があるかを見る。
2. あれば全部読み、書かれたものは**変える前に必ず確認する**（作る役・直す役）。審査役は、指摘に「守るもの」と明記する（直す前に確認が要ることを示すため）。
3. 書かれていなくても、ロゴ・ブランド色・スライドマスタ・顧客の部品らしきものを見つけたら、直す前に一覧で確認する。
4. ファイルが無く、守るものが多そうなプロジェクトでは、作業の終わりに「`DADS-PROTECT.md` を置くと次から確認が減る」と一言添えてよい（勝手に作らない）。
